# Contributing to the Agentic Workflow Protocol

Thank you for helping. This file applies to every repository of the organisation that has no
contributing guide of its own.

- Questions and ideas: [GitHub Discussions](https://github.com/agenticworkflowprotocol/agenticworkflowprotocol.org/discussions).
- Bugs and small changes: an issue or a pull request in the repository concerned.
- Changes to the specification: an [AWP Enhancement Proposal](https://github.com/agenticworkflowprotocol/agenticworkflowprotocol.org/blob/main/docs/aep-process.md).
- Commits use [Conventional Commits](https://www.conventionalcommits.org/) and are signed off
  under the [Developer Certificate of Origin](https://developercertificate.org/) (`git commit -s`).
- Every repository runs its tests with `npm test`; please run them before opening a pull request.

The full guide, including how decisions are made, is in the
[specification repository](https://github.com/agenticworkflowprotocol/agenticworkflowprotocol.org/blob/main/CONTRIBUTING.md).
