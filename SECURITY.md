# Security Policy

Please do not open public issues for security problems. Report them privately with GitHub private
vulnerability reporting in the repository concerned, or to info@agenticworkflowprotocol.org.

Problems in the specification itself (for example semantics that let a conforming runtime bypass
a governance control) follow the
[security policy of the specification](https://github.com/agenticworkflowprotocol/agenticworkflowprotocol.org/blob/main/SECURITY.md).
We acknowledge reports within 3 working days.
